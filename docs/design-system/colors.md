# **🎨 Palette de Couleurs - Palet Vendéen Design System**

> *Inspiré de la maquette homepage.svg et de l'identité visuelle du palet vendéen*

---

## **📌 Philosophie des Couleurs**

La palette reflète :
- **L'héritage vendéen** : Verts profonds (forêts, campagne)
- **Le prestige** : Doré (métal des palets en laiton)
- **La tradition** : Rouge terre cuite (argile des terrains)
- **La modernité** : Contraste clair avec des grisés pour la lisibilité

## **⚡ Couleurs Sémantiques**

### **Statut**

| État | Couleur | Code Hex | Usage |
|------|---------|----------|-------|
| **Succès** | Vert | `#2ecc71` | Match gagné, validation |
| **En cours** | Jaune | `#f39c12` | Manche en cours, attention |
| **Échec/Danger** | Rouge | `#e74c3c` | Match perdu, erreur |
| **Information** | Bleu | `#3498db` | Info neutre |
| **Désactivé** | Gris | `#95a5a0` | Élément inactif |

### **Classement**

| Position | Couleur | Code Hex | Usage |
|----------|---------|----------|-------|
| **Finale** | Vert foncé | `#1a6b4c` | Top 2 |
| **Barrage** | Doré | `#f5d576` | 3ème position |
| **Descente** | Rouge | `#e74c3c` | Zone de relégation |

### **Équipes**
- **Couleur par club** : Utiliser les couleurs primaires (vert) avec des teintes distinctes
- **Exemple** : La Roche-sur-Yon = `#0d3b2e`, Fontenay = `#1a6b4c`, Luçon = `#0a2e23`

## **✨ Bonnes Pratiques**

### **Accessibilité**
- **Contraste minimum** : 4.5:1 pour les textes normaux (AA), 3:1 pour les grands textes
- **Testez toujours** : Utiliser des outils comme [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)
- **Évitez** : Le rouge seul pour les erreurs (associer avec une icône ou du texte)

### **Hierarchie Visuelle**
- **Primary** : `#0d3b2e` (70-80% des surfaces)
- **Secondary** : `#1a6b4c` (15-20%)
- **Accent** : `#f5d576` (5-10%)
- **Danger** : `#e74c3c` (5% max)

### **Couleurs par Composant**
| Composant | Couleur Principale | Couleur Secondaire |
|-----------|-------------------|---------------------|
| Header | `#0d3b2e` | `#0a2e23` |
| Footer | `#071f17` | `#0a2e23` |
| Boutons CTA | `#f5d576` | `#0d3b2e` (texte) |
| Cartes | `#ffffff` | `#dbe5df` (bordure) |
| Tableaux | `#ffffff` | `#dbe5df` (lignes) |
| Badges | `#2ecc71`/`#f39c12`/`#e74c3c` | `#ffffff` (texte) |
