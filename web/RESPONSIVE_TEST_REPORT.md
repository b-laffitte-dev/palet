## 🧪 Tests à Effectuer

### 1. Navigation
- [ ] Menu hamburger visible sur mobile
- [ ] Menu hamburger fonctionne au clic
- [ ] Navigation horizontale sur desktop
- [ ] Logo correctement redimensionné
- [ ] Barre du haut (TopBar) visible et lisible

### 2. Layout
- [ ] Layout plein écran sur mobile
- [ ] Layout avec marges sur desktop
- [ ] Footer correctement positionné
- [ ] Espacement vertical cohérent

### 3. Cartes
- [ ] Cartes en une colonne sur mobile
- [ ] Cartes en 2 colonnes sur tablette
- [ ] Cartes en 3-4 colonnes sur desktop
- [ ] Contenu des cartes lisible
- [ ] Images dans les cartes responsives

### 4. Tableaux
- [ ] Tableaux scrollables horizontalement sur mobile
- [ ] Première colonne fixe sur mobile
- [ ] Tableaux complets sur desktop
- [ ] Texte dans les cellules lisible

### 5. Formulaires
- [ ] Champs en une colonne sur mobile
- [ ] Champs en 2 colonnes sur desktop (si applicable)
- [ ] Boutons pleine largeur sur mobile
- [ ] Labels lisibles

### 6. Images et Médias
- [ ] Images redimensionnées correctement
- [ ] Pas de débordement horizontal
- [ ] Qualités d'image optimisées

### 7. Texte
- [ ] Taille de police adaptée
- [ ] Espacement entre lignes correct
- [ ] Texte lisible sur tous les écrans

### 8. Boutons
- [ ] Taille suffisante pour le toucher sur mobile
- [ ] Espacement entre boutons
- [ ] States (hover, active) visibles

### 9. Performance
- [ ] Temps de chargement acceptable sur mobile
- [ ] Scroll fluide
- [ ] Pas de lag sur les animations

### 10. Accessibilité
- [ ] Focus visible au clavier
- [ ] Ordre de tabulation logique
- [ ] Texte alternatif sur les images
- [ ] Contraste des couleurs suffisant
